# Reference discovery and selection

Before designing a new spreadsheets, search the user's relevant connected sources for previous spreadsheets. If suitable candidates are found, ask: "Which previous spreadsheets should I base this on?"

Skip discovery and the question when the user has already chosen a reference or template, explicitly requested a fresh design, or declined reuse. If the user delegates the choice, search and prefer a suitable previous spreadsheets without asking.
First search for previous spreadsheets on the topic. If that finds no suitable spreadsheets, broaden to spreadsheets with a similar purpose or audience from the user or team.

Search outward, stopping when suitable candidates are found:

1. The user's most recent spreadsheets on the same topic, including the same recurring series. Prefer spreadsheets they created or contributed to.
2. Their team's spreadsheets on the same topic and type.
3. spreadsheets with a similar purpose or audience, first from the user, then their team.

Within each group, rank by fit and prefer the latest suitable version. Lead with actual previous spreadsheets and recommend the strongest fit. Label each option with its title.

If the search finds no suitable previous spreadsheets, continue from the user's request with a fresh design. Do not search generic templates as a fallback.
