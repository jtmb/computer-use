# Reference discovery and selection

Before designing a new documents, search the user's relevant connected sources for previous documents. If suitable candidates are found, ask: "Which previous documents should I base this on?"

Skip discovery and the question when the user has already chosen a reference or template, explicitly requested a fresh design, or declined reuse. If the user delegates the choice, search and prefer a suitable previous documents without asking.
First search for previous documents on the topic. If that finds no suitable documents, broaden to documents with a similar purpose or audience from the user or team.

Search outward, stopping when suitable candidates are found:

1. The user's most recent documents on the same topic, including the same recurring series. Prefer documents they created or contributed to.
2. Their team's documents on the same topic and type.
3. documents with a similar purpose or audience, first from the user, then their team.

Within each group, rank by fit and prefer the latest suitable version. Lead with actual previous documents and recommend the strongest fit. Label each option with its title.

If the search finds no suitable previous documents, continue from the user's request with a fresh design. Do not search generic templates as a fallback.
