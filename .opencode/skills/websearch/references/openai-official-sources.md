# Official OpenAI sources for explicit product/API questions

Read only for explicit OpenAI product/API documentation, model capability,
migration, price or entitlement questions. This is not a mandatory detour for
ordinary code inspection, generic research or search-provider setup. Use the
consumer's exposed research tools and its applicable authority/privacy rules.

## Identify the product before choosing sources

- **Developer API:** start from [OpenAI developer documentation](https://developers.openai.com/)
  and its current model, endpoint, pricing or migration pages. Open the specific
  page supporting the claim, not just a catalog snippet or recommendation.
- **ChatGPT product/account:** use [OpenAI Help](https://help.openai.com/) and
  official product/release documentation relevant to the user's plan. Public
  documentation does not establish account entitlement, current quota, workspace
  admin rights or that a feature is enabled for this user.
- **Codex:** consult Codex documentation only when that is the named product.
  OpenCode is not Codex; “this app” or “you” does not identify an OpenAI product.
  For OpenCode behavior, use the available OpenCode skill and
  [official V2 docs](https://opencode.ai/v2/docs/), plus the installed contract.
- **Third parties:** a third-party OpenAI-compatible endpoint can differ in model
  IDs, tools, authentication, limits and billing. First-party API documentation
  does not prove compatibility or authorize changing the selected provider.

## Preserve requested identity and scope

Preserve the exact requested model, snapshot, provider and effort setting. Do not
silently replace it with a recommended “latest,” cheaper or similarly named model.
If support is uncertain, check the exact model/endpoint/SDK version and report
the gap. A deprecation recommendation is information, not migration authority.
Separate a model's documented capability from what the actual connector exposes;
do not invent parameters or promise a feature from a model-family label.

Use current [model documentation](https://developers.openai.com/api/docs/models)
and [deprecation notices](https://developers.openai.com/api/docs/deprecations) as
discovery points. Follow relevant links for the exact question. This reference is
not a static latest-model, price, context-window or retirement-date snapshot.

## Billing and access are separate evidence

The [ChatGPT/API billing guide](https://help.openai.com/en/articles/9039756-billing-settings-in-chatgpt-vs-platform)
describes separate billing systems. It also mentions eligible promotional credits
for linked API organizations; do not turn this into either “all subscriptions
include API credits” or “subscriptions can never provide API credits.” Verify
current eligibility terms without reading private billing data or signing in on
the user's behalf. Do not infer API access, connector allowance or account balance
from an active ChatGPT session, subscription name or successful text response.

For prices, verify the exact model, units, cached/input/output categories and any
tool/storage or service-tier charges on the current official pricing page. State
what is uncertain instead of quoting an undated memory. A public list price is not
the user's bill or permission for paid requests.

## Research without changing the environment

Use only available search/fetch schemas; cite the actual supporting page and check
date. Missing tools or denied access remain explicit limits, not permission to
invent citations, retry through another credential or install a docs connector.
Do not configure a provider, alter models/defaults/permissions, sign in, add API
credentials, accept billing or issue a model request just to verify documentation.
Do not send private prompts, code, account details or secrets to public search.
