# Self-learning usage

Use this skill to request a review of recurring project-session patterns and
proposed reusable skill guidance. The skill describes agent behavior; it does
not install or guarantee a session tool. Supporting guides are not loaded
automatically with `SKILL.md`.

Example request: “Review this project's sessions for repeated workflow problems
and show me proposed skill changes without applying them.”

First verify the selected project, a supported bounded reader, and effective
permissions. Review pattern evidence and current skill sources, then show a
generalized, non-quoting diff in chat. Explicit approval is required before
applying each exact generated change, including required usage-guide and catalog
diffs. Before editing, check canonical sources, Git state and native permissions;
re-review changed content rather than applying a stale preview. A hash is not
approval or a lock. Validate the complete bundle and preserve conflicting changes
on failure. Deployment is separate; never persist private transcripts or secrets.

For this repository, the optional [experimental source](../../../tools/self-learning/README.md)
documents an unverified plugin adapter; it is not an available tool merely
because its source exists. The [coverage audit](../../../docs/computer-use-tool-coverage-audit.md)
separates executable tools from skill instructions. Consumers must discover
their own integrations rather than assuming these repository-specific paths.
