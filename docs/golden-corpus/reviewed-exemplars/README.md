# Reviewed exemplars — all candidates

Despite the collection name, **nothing here has been human-reviewed**. All six
entries are `candidate` with `review.status: "unreviewed"`. The name marks the
intended destination of the collection, not its current quality tier.

Each exemplar in [`index.json`](index.json):

- belongs to one of the six behavioral categories;
- links to one or more synthetic case IDs;
- lists an observable sequence of actions rather than a mandated tool script;
- states `notEvidenceFor`, so readers cannot mistake it for runtime proof;
- cites reference IDs for provenance;
- remains separate from the behavioral cases and their controls.

## Why candidates are still useful

A candidate exemplar gives a human reviewer something concrete to accept,
rewrite, or reject. It also keeps the intended behavior visible to case authors
without silently becoming an answer key or a required wording. The behavioral
cases, not these prose examples, define the graded outcomes.

## Promotion gate

Promotion to `gold` requires a recorded human review, a non-automated reviewer
identity, a review date, and evidence. The validator checks those declared
fields; it cannot authenticate the reviewer or judge review quality. Until such a
review actually occurs, every entry stays candidate and the collection manifest
stays unreviewed.

None of these exemplars contains a private transcript, user conversation,
credential, or token. They are synthetic teaching examples.
