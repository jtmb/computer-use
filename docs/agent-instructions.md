## Prevent omissions and preserve decisions

Keep one [request coverage index](request-coverage.md), not a second goal store.
Every selected source requirement maps to a current task/artifact, completed
evidence, a cited later user supersession, or an explicit blocker. Goal cancellation,
one successful worker and a shorter summary do not waive other requirements.
At material scope/decision changes, accepted phase boundaries and handoff/closure,
parent checks coverage and selected repo archive against supported live goal tools.
Retain original decisions/reasons/actions/evidence and link later changes instead
of rewriting history. Bounded exports cannot prove every prior revision survives.
No huge always-loaded checklist, polling loop or permanent reviewer ceremony.
